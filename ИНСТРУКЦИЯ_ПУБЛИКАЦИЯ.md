# ИНСТРУКЦИЯ: Публикация на GitHub

## ШАГ 1: Создание репозитория на GitHub

### 1.1 Откройте браузер
- Перейдите на **https://github.com**
- Войдите в свой аккаунт

### 1.2 Создайте новый репозиторий
1. Нажмите на **иконку "+"** в правом верхнем углу (рядом с вашим аватаром)
2. Выберите **"New repository"** из выпадающего меню

### 1.3 Заполните форму создания
| Поле | Значение |
|------|----------|
| **Repository name** | `dnd-character-manager` |
| **Description** | `Offline-first D&D 5e character management engine with Trinity State architecture` |
| **Visibility** | ✅ **Public** (для портфолио) |
| **Initialize with README** | ❌ НЕ ставьте галочку (у нас уже есть README) |
| **Add .gitignore** | ❌ НЕ выбирайте (у нас уже есть) |
| **Choose a license** | ❌ НЕ выбирайте (у нас уже есть MIT) |

### 1.4 Нажмите кнопку
- **Зелёная кнопка "Create repository"** внизу формы

## ШАГ 2: Подключение remote (в терминале)

### 2.1 Откройте терминал в папке проекта
- Откройте **Android Studio**
- Внизу нажмите вкладку **"Terminal"**
- Или откройте **PowerShell / CMD** и перейдите в папку:
```
cd F:\app\DnD
```

### 2.2 Добавьте remote (замените USERNAME на ваш логин GitHub)

**ВАЖНО:** Скопируйте URL из созданного репозитория (GitHub покажет его после создания)

```bash
git remote add origin https://github.com/USERNAME/dnd-character-manager.git
```

### 2.3 Проверьте что remote добавлен
```bash
git remote -v
```

Должно показать:
```
origin  https://github.com/USERNAME/dnd-character-manager.git (fetch)
origin  https://github.com/USERNAME/dnd-character-manager.git (push)
```

## ШАГ 3: Пуш на GitHub

### 3.1 Отправьте код
```bash
git push -u origin master
```

### 3.2 Если спросит авторизацию
- **Вариант A:** Введите логин и пароль GitHub
- **Вариант B:** Если включена 2FA, создайте Personal Access Token:
  1. GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
  2. "Generate new token (classic)"
  3. Выберите scopes: `repo` (все галочки в разделе repo)
  4. Скопируйте токен и используйте его как пароль

## ШАГ 4: Проверка

### 4.1 Откройте репозиторий в браузере
```
https://github.com/USERNAME/dnd-character-manager
```

### 4.2 Проверьте:
- [ ] README.md отображается на главной странице
- [ ] Бейджи (Kotlin, Compose, etc.) видны
- [ ] Папка `app/` содержит исходный код
- [ ] Нет папок "app — копия (2/3/4)"
- [ ] Нет папки `.idea/`
- [ ] Размер репозитория разумный (~5-10 MB)

## ШАГ 5: Добавление скриншотов (опционально)

### 5.1 Создайте папку для изображений
```bash
mkdir -p docs/screenshots
```

### 5.2 Добавьте скриншоты
- Сделайте скриншоты приложения на эмуляторе/устройстве
- Сохраните в `docs/screenshots/`
- Рекомендуемые имена:
  - `character_sheet.png`
  - `wild_shape.gif`
  - `combat_tab.png`
  - `spells_tab.png`
  - `tactical_cast.gif`

### 5.3 Обновите README
Замените плейсхолдеры в README:
```markdown
| Feature | Screenshot |
|---------|------------|
| Character Sheet | ![Sheet](docs/screenshots/character_sheet.png) |
```

### 5.4 Закоммитьте и запушьте
```bash
git add docs/
git commit -m "Add screenshots"
git push
```

## ШАГ 6: Настройка репозитория (опционально)

### 6.1 Добавьте topics (теги)
1. Откройте репозиторий на GitHub
2. Нажмите **шестерёнку** рядом с "About"
3. В поле **Topics** добавьте:
   - `android`
   - `kotlin`
   - `jetpack-compose`
   - `dnd`
   - `dungeons-and-dragons`
   - `character-manager`
   - `clean-architecture`

### 6.2 Добавьте ссылку на сайт (если есть)
В том же окне "About":
- **Website:** ссылка на ваше портфолио или Google Play

### 6.3 Включите GitHub Pages (для демо-сайта)
1. Settings → Pages (левое меню)
2. Source: **Deploy from a branch**
3. Branch: **master** → **/(root)**
4. Save

## Если что-то пошло не так

### Ошибка: "remote origin already exists"
```bash
git remote remove origin
git remote add origin https://github.com/USERNAME/dnd-character-manager.git
```

### Ошибка: "failed to push some refs"
```bash
git pull origin master --allow-unrelated-histories
git push -u origin master
```

### Ошибка: "Authentication failed"
- Используйте Personal Access Token вместо пароля
- GitHub → Settings → Developer settings → Personal access tokens
